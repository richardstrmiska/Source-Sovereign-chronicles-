## 🛠 Technical Notes
- Artwork files ≤ 100 MB tracked with **Git LFS** (`*.png`, `*.jpg`, `*.tif`, `*.psd`).  
- Each image has a matching JSON metadata file with:
  - `title`, `timestamp_iso`, `checksum`, and `palette`.  
- Zipped release bundles in `/exports` for offline archival.
